# LangChain Learning Repository

This repository contains my code implementations and learning notes from my journey of learning **LangChain**.

## About This Repository

I learned LangChain through **Nitish Sir's CampusX lectures**. During the Mentox AI Bootcamp at LNMIIT, I received weekly PDF materials containing links to the corresponding video lectures and topics to be covered.

As part of the bootcamp, I completed all the weekly learning materials and implemented the concepts covered in the lectures by writing and experimenting with code.

This repository is a collection of those implementations, organized to keep track of everything I learned and to serve as a reference for future projects.

## Learning Resources

- **Course:** LangChain by CampusX
- **Instructor:** Nitish Sir
- **Learning Platform:** CampusX
- **Additional Learning:** Weekly PDFs provided during the Mentox AI Bootcamp at LNMIIT.

## Topics Covered

The repository includes implementations of various LangChain concepts, including:

- LangChain Fundamentals
- Language Models and Chat Models
- Prompt Templates
- Output Parsers
- Chains and LCEL
- Document Loaders and Text Splitters
- Embeddings and Vector Databases
- Semantic Search and Retrievers
- Retrieval-Augmented Generation (RAG)
- Building RAG-based Applications and Chatbots
- Working with Multiple LLM APIs
